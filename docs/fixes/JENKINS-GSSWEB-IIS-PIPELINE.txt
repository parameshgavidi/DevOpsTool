JENKINS PIPELINE — GSSWeb TO IIS (LOCAL WINDOWS)
File: docs/fixes/JENKINS-GSSWEB-IIS-PIPELINE.txt

Use this AFTER Jenkins is installed and Git + Pipeline plugins are present
(Installed plugins shows "Git plugin" and "Pipeline").

This is NOT GSS Web Service (ASMX). This is GSSWeb:
  WebV3\gssweb\gssweb.sln
  Shared Components\GSSWebComponent
  FolderProfile publish → copy files into IIS
  Do NOT use dotnet restore / dotnet build.
  Do NOT use the website MSI for this Jenkins job (Copy Files path).

  REPO_ROOT     = F:\GSS\AppDev\gss-root
  MSBUILD_EXE   = F:\Program Files (x86)\Microsoft Visual Studio\2019\Professional\MSBuild\Current\Bin\amd64\MSBuild.exe
  SLN           = F:\GSS\AppDev\gss-root\WebV3\gssweb\gssweb.sln

If Get-Website shows a different site name / folder, swap IIS_SITE_NAME,
IIS_APP_POOL, IIS_PHYSICAL, and IIS_HTTP_PORT to match that site.

If MSBuild is VS 18 / 2022 instead of 2019, swap MSBUILD_EXE only.


================================================================================
PART 1 — CREATE THE IIS SITE ONCE (Administrator PowerShell)
================================================================================
Paste this block. Press Enter. Ignore "already exists" errors.

  Import-Module WebAdministration
  $site = "GSSWeb"
  $pool = "GSSWeb"
  $path = "C:\inetpub\wwwroot\GSSWeb"
  $port = 8081
  if (-not (Test-Path $path)) { New-Item -ItemType Directory -Path $path | Out-Null }
  if (-not (Test-Path "IIS:\AppPools\$pool")) {
      New-WebAppPool -Name $pool
      Set-ItemProperty "IIS:\AppPools\$pool" -Name managedRuntimeVersion -Value "v4.0"
  }
  if (-not (Get-Website -Name $site -ErrorAction SilentlyContinue)) {
      New-Website -Name $site -Port $port -PhysicalPath $path -ApplicationPool $pool
  }
  Get-Website -Name $site
  Get-WebAppPoolState -Name $pool

Browser:  http://localhost:8081/
Empty / placeholder is OK. Jenkins will copy GSSWeb files here.


================================================================================
PART 2 — CREATE THE JENKINS JOB (or update GSSWebIIS)
================================================================================
Job GSSWebIIS already exists on this VDI. Do not create a second job.

1. Jenkins dashboard (http://localhost:8080)
2. Open GSSWebIIS → Configure
3. Pipeline → Definition: Pipeline script
4. Replace the whole script with PART 3 (or replace only
   stage('Get latest GSSWeb') if the rest is already correct)
5. Save
6. If a build is stuck on git fetch, abort it (red X)
7. Build Now
8. Open the new build → Console Output

To create from scratch instead:
1. Dashboard → + New Item → Name: GSSWebIIS → Pipeline → OK
2. Paste PART 3 → Save → Build Now


================================================================================
PART 3 — PIPELINE SCRIPT (paste into the job)
================================================================================
pipeline {
    agent any

    options {
        skipDefaultCheckout()
    }

    environment {
        REPO_ROOT     = 'F:\\GSS\\AppDev\\gss-root'
        MSBUILD_EXE   = 'F:\\Program Files (x86)\\Microsoft Visual Studio\\2019\\Professional\\MSBuild\\Current\\Bin\\amd64\\MSBuild.exe'
        SLN           = 'F:\\GSS\\AppDev\\gss-root\\WebV3\\gssweb\\gssweb.sln'
        SITE_FOLDER   = 'F:\\GSS\\AppDev\\gss-root\\WebV3\\gssweb\\gssweb'
        WEB_DIR       = 'F:\\GSS\\AppDev\\gss-root\\WebV3\\gssweb'
        IIS_SITE_NAME = 'GSSWeb'
        IIS_APP_POOL  = 'GSSWeb'
        IIS_PHYSICAL  = 'C:\\inetpub\\wwwroot\\GSSWeb'
        IIS_HTTP_PORT = '80'
        BACKUP_ROOT   = 'C:\\inetpub\\backups\\GSSWeb'
    }

    stages {
        stage('Get latest GSSWeb') {
            steps {
                bat '''
                    cd /d "%REPO_ROOT%"
                    set GIT_TERMINAL_PROMPT=0
                    git -c credential.helper= fetch || echo FETCH_FAILED using local files
                    git restore --source=@{u} --staged --worktree -- "WebV3\\gssweb" "Shared Components\\GSSWebComponent" || ver > nul
                    git status -sb
                '''
            }
        }

        stage('Build GSSWebComponent + publish GSSWeb') {
            steps {
                powershell '''
                    $msbuild = @(
                        'F:\\Program Files\\Microsoft Visual Studio\\18\\Professional\\MSBuild\\Current\\Bin\\amd64\\MSBuild.exe',
                        'C:\\Program Files\\Microsoft Visual Studio\\2022\\Professional\\MSBuild\\Current\\Bin\\amd64\\MSBuild.exe',
                        $env:MSBUILD_EXE
                    ) | Where-Object { $_ -and (Test-Path $_) } | Select-Object -First 1
                    if (-not $msbuild) {
                        throw "MSBuild not found. Tried VS 18, VS 2022, and MSBUILD_EXE=$($env:MSBUILD_EXE)"
                    }
                    Write-Host "Using MSBuild: $msbuild"
                    if (-not (Test-Path $env:SLN)) {
                        throw "gssweb.sln not found: $($env:SLN)"
                    }

                    $pre = Join-Path $env:WEB_DIR "PrecompiledWeb"
                    if (Test-Path $pre) {
                        Write-Host "Cleaning $pre"
                        Remove-Item $pre -Recurse -Force
                    }

                    $preferred = @(
                        (Join-Path $env:REPO_ROOT "Shared Components\\GSSWebComponent\\GSSWebComponent.csproj"),
                        (Join-Path $env:REPO_ROOT "Shared Components\\GSSWebComponent\\GSSWebComponent\\GSSWebComponent.csproj")
                    ) | Where-Object { Test-Path $_ } | Select-Object -First 1
                    if ($preferred) {
                        $csproj = Get-Item $preferred
                    } else {
                        $csproj = Get-ChildItem -Path (Join-Path $env:REPO_ROOT "Shared Components") -Filter "GSSWebComponent.csproj" -Recurse -ErrorAction SilentlyContinue |
                            Where-Object { $_.FullName -notmatch 'Crystal Reports Backup Files' } |
                            Select-Object -First 1
                    }
                    if (-not $csproj) {
                        throw "GSSWebComponent.csproj not found under Shared Components"
                    }
                    if ($csproj.FullName -match 'Crystal Reports Backup Files') {
                        throw "Refusing backup csproj: $($csproj.FullName)"
                    }
                    Write-Host "Building $($csproj.FullName)"
                    & $msbuild $csproj.FullName /p:Configuration=Release /t:Build /v:m
                    if ($LASTEXITCODE -ne 0) { throw "GSSWebComponent msbuild failed: $LASTEXITCODE" }

                    $dll = @(
                        (Join-Path $csproj.DirectoryName "bin\\Release\\GSSWebComponent.dll"),
                        (Join-Path $csproj.DirectoryName "bin\\Release\\net48\\GSSWebComponent.dll")
                    ) | Where-Object { Test-Path $_ } | Select-Object -First 1
                    if (-not $dll) { throw "GSSWebComponent.dll not found after build" }

                    $bin = Join-Path $env:SITE_FOLDER "Bin"
                    if (-not (Test-Path $bin)) { New-Item -ItemType Directory -Path $bin | Out-Null }
                    Copy-Item $dll (Join-Path $bin "GSSWebComponent.dll") -Force
                    Write-Host "Copied $dll -> $bin\\GSSWebComponent.dll"

                    Write-Host "Skipping gssweb.sln FolderProfile (SSRS MSB4226) and aspnet_compiler (CS1647)"
                    Write-Host "IIS deploy source is the website folder (64-bit app pool compiles on first request)"
                    if (-not (Test-Path (Join-Path $bin "GSSWebComponent.dll"))) {
                        throw "GSSWebComponent.dll missing from site Bin after copy"
                    }
                '''
            }
        }

        stage('Backup IIS') {
            steps {
                powershell '''
                    $stamp = Get-Date -Format "yyyyMMdd-HHmmss"
                    $dest  = Join-Path $env:BACKUP_ROOT $stamp
                    New-Item -ItemType Directory -Path $dest -Force | Out-Null
                    if (Test-Path $env:IIS_PHYSICAL) {
                        Copy-Item (Join-Path $env:IIS_PHYSICAL "*") $dest -Recurse -Force
                    }
                    Write-Host "Backup: $dest"
                '''
            }
        }

        stage('Deploy to IIS') {
            steps {
                powershell '''
                    Import-Module WebAdministration
                    $src = $env:SITE_FOLDER
                    if (-not (Test-Path $src)) { throw "No GSSWeb website folder found: $src" }
                    Write-Host "Deploy source: $src"

                    $dest = $env:IIS_PHYSICAL
                    $pool = $env:IIS_APP_POOL
                    if (-not (Test-Path $dest)) { New-Item -ItemType Directory -Path $dest | Out-Null }

                    Write-Host "Stopping app pool $pool"
                    Stop-WebAppPool -Name $pool -ErrorAction SilentlyContinue
                    $deadline = (Get-Date).AddSeconds(30)
                    do {
                        Start-Sleep -Seconds 1
                        $state = (Get-WebAppPoolState -Name $pool).Value
                    } while ($state -ne "Stopped" -and (Get-Date) -lt $deadline)

                    Get-ChildItem $src -Force |
                        Where-Object { $_.Name -notin @('.git','packages') -and $_.Extension -notin @('.sln','.resx') } |
                        Copy-Item -Destination $dest -Recurse -Force

                    Write-Host "Starting app pool $pool"
                    Start-WebAppPool -Name $pool
                    Start-Sleep -Seconds 2
                    $state = (Get-WebAppPoolState -Name $pool).Value
                    Write-Host "App pool: $state"
                    if ($state -ne "Started") { throw "App pool '$pool' is $state" }
                '''
            }
        }

        stage('Smoke test') {
            steps {
                powershell '''
                    $url = "http://localhost:$($env:IIS_HTTP_PORT)/"
                    Write-Host "GET $url"
                    try {
                        $r = Invoke-WebRequest -Uri $url -UseBasicParsing -TimeoutSec 60
                    } catch {
                        throw "Smoke test failed for $url : $_"
                    }
                    if ($r.StatusCode -ge 400) { throw "HTTP $($r.StatusCode) from $url" }
                    Write-Host "HTTP $($r.StatusCode) from $url"
                '''
            }
        }
    }

    post {
        success {
            echo "GSSWeb is on IIS http://localhost:${env.IIS_HTTP_PORT}/"
        }
        failure {
            echo "Failed. Check Console Output: git, MSBuild path, PrecompiledWeb, IIS app pool."
        }
    }
}

================================================================================
PART 5 — IF A STAGE FAILS
================================================================================
Get latest GSSWeb — git fetch hangs
  Jenkins runs as LocalSystem. A credential GUI never appears, so
  git fetch waits forever. The job disables the prompt and helper:
    set GIT_TERMINAL_PROMPT=0
    git -c credential.helper= fetch || echo FETCH_FAILED using local files
  Fetch may print FETCH_FAILED; the build continues from
  F:\GSS\AppDev\gss-root. To update from origin, run git fetch in
  your own cmd in that folder, then Build Now again.

MSBuild not found
  This VDI uses VS 2019:
    F:\Program Files (x86)\Microsoft Visual Studio\2019\Professional\MSBuild\Current\Bin\amd64\MSBuild.exe
  If that file is missing, swap MSBUILD_EXE to VS 18 or VS 2022.

GSSWebComponent.csproj — Crystal Reports Backup Files
  Recurse + First 1 picked:
    Shared Components\Crystal Reports Backup Files\GSSWebComponent.csproj
  That copy has no .cs files (CS2001) and broken project references.
  Use the real project:
    Shared Components\GSSWebComponent\GSSWebComponent.csproj
    Shared Components\GSSWebComponent\GSSWebComponent\GSSWebComponent.csproj
  Skip any path under "Crystal Reports Backup Files".

gssweb.sln publish — MSB4226 SSRSReports.rptproj
  Do not FolderProfile the .sln.

aspnet_compiler — CS1647
  Precompile fails: "An expression is too long or complex to compile"
  (often currentDispatch.aspx). 32/64-bit aspnet_compiler hits the same limit.
  Copy website folder + fresh Bin\GSSWebComponent.dll to IIS instead.
  64-bit IIS app pool compiles on first request. Smoke test hits http://localhost/

  Paste file: docs/fixes/GSSWebIIS-Jenkins-script-3.txt

MSB3277 TlcDdpDataProcessingTests
  Binding-redirect warnings. They do not fail the build.

MSB4249 / dotnet
  Do not add dotnet restore. GSSWeb is classic ASP.NET Web Site.

CS0117 / CS1061 receptacle APIs
  Stale Bin\GSSWebComponent.dll. See
    docs/fixes/gssweb-receptacle-dll-cs0117-cs1061.txt

App pool stop/start
  Import-Module WebAdministration must work. Run PART 1 as Administrator
  once so the site and pool exist.

Smoke test wrong site
  This VDI serves GSSWeb on port 80. Smoke test is http://localhost/
  Jenkins is 8080 — do not point IIS_HTTP_PORT at 8080.
