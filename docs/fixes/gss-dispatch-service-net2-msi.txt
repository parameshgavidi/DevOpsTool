THREE PROBLEMS THAT CAUSE EXIT != 0
--------------------------------------------------------------------------------
1) appsettings paths do not match Explorer
   projectPath must be ...\GSSDispatchService\GSSDispatchServiceNet2.csproj
   (not ...\DispatchService\...)
   setupProjectPath must be ...\GSSDispServiceSetup\GSSDispServiceSetup.vdproj
   setupSolutionPath must be ...\GSSDispatchService\GSSDispatchServiceNet2.sln

2) GSSDispatchServiceNet2.sln likely does NOT contain the Setup project
   The .sln sits inside the service folder (7/8). The .vdproj is a
   sibling folder and is newer (8/28). If Solution Explorer does not
   show GSSDispServiceSetup, devenv /project "GSSDispServiceSetup"
   fails → line 710.

3) BuildSetupProjectAsync fallback cannot find this .sln
   Fallback only does GetFiles(parentOfSetupDir, "*.sln") — that is
   "GSS Dispatch Service\*.sln". Your .sln is one folder deeper.
   If setupSolutionPath is wrong, you get "Setup solution not found"
   OR a bad file. Also Setup args logs are commented, so you cannot
   see the devenv command.
