GOAL
----
When the user picks a different value in "Get Latest From Repo Branch",
clear the "build file path" label (ResolvedBuildFilePath).

The old path is stale for the new branch. Example from your screenshot:

    Get Latest From Repo Branch:  GSSv9.252
    build file path label:        F:\build-output\9.351

Change the dropdown → the label must go blank. Click "Build file path"
again to show the path for the newly selected branch.

NO new appsettings / configuration variable.

================================================================================
CHANGE 2 — ADD OnRepoFromBranchChanged (inside @code / BuildTab.razor.cs)
================================================================================
PASTE next to BuildFilePathClicked / RepoFromBranch.

    private Task OnRepoFromBranchChanged(ChangeEventArgs e)
    {
        RepoFromBranch = e.Value?.ToString()?.Trim() ?? string.Empty;
        ResolvedBuildFilePath = string.Empty;
        return InvokeAsync(StateHasChanged);
    }

What this does:
  1. Writes the newly selected branch into RepoFromBranch (replaces @bind).
  2. Clears the "build file path" label so F:\build-output\9.351 disappears.
  3. Re-renders. The @if (!string.IsNullOrWhiteSpace(ResolvedBuildFilePath))
     span is hidden until the user clicks "Build file path" again.
