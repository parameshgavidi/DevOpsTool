--------------------------------------------------------------------------------
WHAT THE ISSUE IS
--------------------------------------------------------------------------------
VS 2026 Insiders (product version 18) is a BROKEN / half-uninstalled
instance. Three failures stacked:

1) FileTracker MSI 1612  (the real blocker)
   Windows Installer must re-open the original .msi to uninstall.
   That cached source is gone (cleaned cache, moved folder, or the
   package was installed from a path that no longer exists).
   Return 1612 = ERROR_INSTALL_SOURCE_ABSENT.
   Until this MSI is removed or repaired, the VS 2026 modify /
   uninstall cannot finish.

2) Copilot Log Viewer finalizer crash  (0xE0434352)
   The installer asked Extensibility.Finalizer.exe to uninstall
   CopilotLogViewer. That process crashed.
   The command line shows the install is SPLIT across drives:
     Finalizer.exe  = C:\Program Files\Microsoft Visual Studio\18\...
     Extension      = F:\Program Files\Microsoft Visual Studio\18\...
   That split C: / F: layout is leftover from the older VS 18
   Professional-on-F: install. The Insiders instance is not a
   clean single-folder install.

3) Product.Enterprise finalize  (Incorrect function)
   This is a CASCADE. vs_finalizer.exe runs after the two
   failures above. It is not a separate product bug.

None of this is caused by GssDevOpsAutomationTool targeting
.net10 / net8.


--------------------------------------------------------------------------------
WHAT TO DO (pick one path)
--------------------------------------------------------------------------------
PATH A — keep working (recommended)
  Ignore VS 2026. Close the dialog. Launch Visual Studio 2022.
  Continue the net8 retarget.

PATH B — clean up VS 2026 so the red warning goes away
  Repair or force-remove the Insiders instance only.
  Do NOT run InstallCleanup.exe -f  (that can damage VS 2022
  and VS 2019).


--------------------------------------------------------------------------------
PATH A — use VS 2022 now (no VS 2026 fix required)
--------------------------------------------------------------------------------
1. In the installer dialog click Close.
2. On Visual Studio Enterprise 2022 click Launch
   (or Start menu → Visual Studio 2022).
3. Open GssDevOpsAutomationTool.sln.
4. Follow:
     docs/fixes/vs2022-retarget-gssdevops-from-net10.txt

VS 2022 also says "Setup completed with warnings". That is OK
as long as Launch works and you can open a new Console / MAUI
project. Do not Repair VS 2022 unless it fails to start.


--------------------------------------------------------------------------------
PATH B — clean VS 2026 Insiders (optional)
--------------------------------------------------------------------------------
Close ALL Visual Studio windows and the installer first.


STEP B1 — Repair VS 2026 (restores the missing MSI cache)

1. Open Visual Studio Installer as Administrator
   (right-click → Run as administrator).
2. Visual Studio Enterprise 2026 Insiders → More → Repair.
3. Wait. If Repair succeeds, then More → Uninstall.

If Repair fails with the same 1612 / FileTracker error,
go to STEP B2. Do not keep clicking Uninstall.


STEP B2 — remove the stuck FileTracker MSI (1612)

Windows cannot uninstall Microsoft.Build.FileTracker.Msi
because the cached .msi is missing.

Use Microsoft's Program Install and Uninstall troubleshooter:

  https://support.microsoft.com/en-us/topic/
  fix-problems-that-block-programs-from-being-installed-or-removed
  -cca7d1b6-65a9-3d98-426b-e9f927e1eb4d

Or search Microsoft for:  "Program Install and Uninstall troubleshooter"

Run it:
  1. Uninstalling
  2. Find Microsoft.Build.FileTracker.Msi  (or "FileTracker")
  3. Yes, try to uninstall

ProductCode from your log (if the list does not show a name):

  {2B48BBFA-3D0EA-45225-AEBB-37F25940F016}

After the troubleshooter, reopen Visual Studio Installer
and try Uninstall on VS 2026 Insiders again.


STEP B3 — if CopilotLogViewer is still listed

The finalizer crashed because the extension folder is on F:
and the IDE bits are on C:.

Check which of these exist:

  dir "C:\Program Files\Microsoft Visual Studio\18\Enterprise"
  dir "F:\Program Files\Microsoft Visual Studio\18\Enterprise"
  dir "F:\Program Files\Microsoft Visual Studio\18\Professional"

If CopilotLogViewer exists only on F: and the rest is on C:,
you can rename (do not delete yet) the leftover F: extension:

  F:\Program Files\Microsoft Visual Studio\18\Enterprise\Common7\IDE\Extensions\Microsoft.CopilotLogViewer

Then run Repair / Uninstall again from the installer.


STEP B4 — last resort: InstallCleanup for version 18 ONLY

Use this only if Repair + troubleshooter still leave VS 2026
stuck. Run an elevated Command Prompt (Admin):

  cd "C:\Program Files (x86)\Microsoft Visual Studio\Installer"
  InstallCleanup.exe -i 18

  -i 18  = remove VS 18 / 2026 products only.

DO NOT run:

  InstallCleanup.exe -f

-f removes shared components used by VS 2022 and VS 2019.

After -i 18:

  1. Reopen Visual Studio Installer
  2. VS 2026 Insiders should be gone (or offer Install)
  3. Confirm Visual Studio Enterprise 2022 still shows Launch
  4. Launch VS 2022 and open a simple project as a smoke test
