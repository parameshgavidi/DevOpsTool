WHY YOU SEE ERRORS (from current BuildTab / appsettings)
--------------------------------------------------------------------------------
Your screenshots already call BuildSetupProjectAsync after a successful web
build. These bugs still break MSI → build-output:

1) AspNetMvc publish folder is never found
   BuildTab only looks under PrecompiledWeb for GSS Web Service / GSSWeb.
   Web2ClientBridge FolderProfile publishes to:
     WebToClientBridge\WebToClientBridge\bin\Release\Publish\
   Result in log:
     [WARN] Publish output not found for Web2ClientBridge under ...
   Web site files never land in F:\build-output\Web2ClientBridge.

2) MSI source folder too narrow
   Code only checks:
     Web2ClientBridge.Setup\Release
     Web2ClientBridge.Setup\Debug
   If devenv put the .msi one level deeper (or only the .msi exists elsewhere
   under the setup project), you get:
     [WARN] Setup output folder not found for Web2ClientBridge: ...\Release
   and nothing is copied to build-output.

3) Final Status ignores setupExit
   After BuildSetupProjectAsync returns setupExit != 0, status still uses
   only the web build exit code → UI shows Success while MSI failed.

4) .vdproj cannot use msbuild
   MSB4078 is expected if you point projectPath at the .sln / .vdproj.
   Web = msbuild on .csproj. Setup MSI = devenv.exe on .vdproj via .sln.

5) Missing / unbound Application properties
   If SetupProjectPath / SetupBuildCommand are not on the Application model
   (or not loaded from appsettings), BuildSetupProjectAsync never runs
   (SetupProjectPath is null/empty).

--------------------------------------------------------------------------------
PART D — BuildSetupProjectAsync (REPLACE your method with this)
--------------------------------------------------------------------------------
Fixes vs your current method:
  - Prefer app.SetupSolutionPath from appsettings (not only hard-coded .sln)
  - Fall back: sibling .sln next to setup folder / first .sln in parent
  - After devenv succeeds, find *.msi under the setup project (not only
    Release/Debug folder existence)
  - Copy MSI (+ supporting setup files) to:
      F:\build-output\Web2ClientBridge\Setup\

    private async Task<int> BuildSetupProjectAsync(
        Application app, string outputFolder, CancellationToken cancellation)
    {
        var setupProjectFile = GetConfiguredPath(app.SetupProjectPath);
        if (string.IsNullOrWhiteSpace(setupProjectFile) || !File.Exists(setupProjectFile))
        {
            LogOutput += $"[{DateTime.Now:HH:mm:ss}] [ERROR] Setup project not found for {app.Name}: {app.SetupProjectPath}\r\n";
            return -1;
        }

        var setupProjectDir = Path.GetDirectoryName(setupProjectFile)!;
        var setupProjectName = Path.GetFileNameWithoutExtension(setupProjectFile);

        // 1) appsettings setupSolutionPath  2) hard-coded sibling  3) discover *.sln
        string? setupSolutionPath = null;
        if (!string.IsNullOrWhiteSpace(app.SetupSolutionPath))
            setupSolutionPath = GetConfiguredPath(app.SetupSolutionPath);

        if (string.IsNullOrWhiteSpace(setupSolutionPath) || !File.Exists(setupSolutionPath))
        {
            var parent = Path.GetDirectoryName(setupProjectDir);
            var candidate = parent is null
                ? null
                : Path.Combine(parent, "WebToClientBridge.sln");
            if (!string.IsNullOrEmpty(candidate) && File.Exists(candidate))
                setupSolutionPath = candidate;
            else if (!string.IsNullOrEmpty(parent))
                setupSolutionPath = Directory.GetFiles(parent, "*.sln").FirstOrDefault();
        }

        if (string.IsNullOrWhiteSpace(setupSolutionPath) || !File.Exists(setupSolutionPath))
        {
            LogOutput += $"[{DateTime.Now:HH:mm:ss}] [ERROR] Setup solution (.sln) not found for {app.Name}\r\n";
            return -1;
        }

        var devenvPath = BuildService.ResolveVisualStudioIdePath();
        if (string.IsNullOrWhiteSpace(devenvPath) || !File.Exists(devenvPath))
        {
            LogOutput += $"[{DateTime.Now:HH:mm:ss}] [ERROR] devenv.exe not found. Install Visual Studio + Installer Projects for .vdproj.\r\n";
            return -1;
        }

        var command = string.IsNullOrWhiteSpace(app.SetupBuildCommand)
            ? "\"{devenvPath}\" \"{setupSolutionPath}\" /build Release /project \"{setupProjectName}\" /projectconfig Release"
            : app.SetupBuildCommand;

        command = command
            .Replace("{setupProjectFile}", setupProjectFile, StringComparison.OrdinalIgnoreCase)
            .Replace("{setupProjectDir}", setupProjectDir, StringComparison.OrdinalIgnoreCase)
            .Replace("{setupSolutionPath}", setupSolutionPath, StringComparison.OrdinalIgnoreCase)
            .Replace("{setupProjectName}", setupProjectName, StringComparison.OrdinalIgnoreCase)
            .Replace("{devenvPath}", devenvPath, StringComparison.OrdinalIgnoreCase)
            .Replace("{outputFolder}", outputFolder, StringComparison.OrdinalIgnoreCase);

        LogOutput += $"[{DateTime.Now:HH:mm:ss}] [INFO] Building setup MSI for {app.Name}...\r\n";
        LogOutput += $"[{DateTime.Now:HH:mm:ss}] [INFO] Setup command: {command}\r\n";

        StartLogFlushTimer();
        var exit = await BuildService.RunCommandAsync(
            setupProjectDir,
            command,
            line =>
            {
                lock (_pendingLogBuffer)
                {
                    _pendingLogBuffer.Append(line);
                }
                app.LogEntries.Add(line.TrimEnd('\r', '\n'));
            },
            cancellation);
        FlushPendingLogs();

        if (exit != 0)
        {
            LogOutput += $"[{DateTime.Now:HH:mm:ss}] [ERROR] Setup build failed for {app.Name} with exit code {exit}\r\n";
            return exit;
        }

        // Prefer Release, then Debug, then any *.msi under the setup project tree
        string? setupSourceDir = null;
        var releaseDir = Path.Combine(setupProjectDir, "Release");
        var debugDir = Path.Combine(setupProjectDir, "Debug");
        if (Directory.Exists(releaseDir) &&
            Directory.EnumerateFiles(releaseDir, "*.msi", SearchOption.AllDirectories).Any())
            setupSourceDir = releaseDir;
        else if (Directory.Exists(debugDir) &&
                 Directory.EnumerateFiles(debugDir, "*.msi", SearchOption.AllDirectories).Any())
            setupSourceDir = debugDir;
        else
        {
            var anyMsi = Directory.Exists(setupProjectDir)
                ? Directory.GetFiles(setupProjectDir, "*.msi", SearchOption.AllDirectories)
                    .OrderByDescending(File.GetLastWriteTimeUtc)
                    .FirstOrDefault()
                : null;
            if (!string.IsNullOrEmpty(anyMsi))
                setupSourceDir = Path.GetDirectoryName(anyMsi);
        }

        if (string.IsNullOrEmpty(setupSourceDir) || !Directory.Exists(setupSourceDir))
        {
            LogOutput += $"[{DateTime.Now:HH:mm:ss}] [ERROR] Setup MSI not found under {setupProjectDir} (checked Release/Debug and *.msi).\r\n";
            return -1;
        }

        var setupDestFolder = Path.Combine(
            outputFolder,
            string.IsNullOrWhiteSpace(app.SetupOutputSubfolder) ? "Setup" : app.SetupOutputSubfolder);

        if (Directory.Exists(setupDestFolder))
            Directory.Delete(setupDestFolder, recursive: true);
        Directory.CreateDirectory(setupDestFolder);

        foreach (var file in Directory.GetFiles(setupSourceDir, "*", SearchOption.AllDirectories))
        {
            var relative = Path.GetRelativePath(setupSourceDir, file);
            var dest = Path.Combine(setupDestFolder, relative);
            Directory.CreateDirectory(Path.GetDirectoryName(dest)!);
            File.Copy(file, dest, overwrite: true);
        }

        var msiCopied = Directory.GetFiles(setupDestFolder, "*.msi", SearchOption.AllDirectories);
        LogOutput += $"[{DateTime.Now:HH:mm:ss}] [INFO] Setup output copied to {setupDestFolder}" +
                     (msiCopied.Length > 0
                         ? $" ({string.Join(", ", msiCopied.Select(Path.GetFileName))})"
                         : " (warning: no .msi in copied files)") + "\r\n";

        return 0;
    }

--------------------------------------------------------------------------------
ERROR: Setup project not found
  → setupProjectPath wrong or Application.SetupProjectPath not bound

ERROR: Setup solution (.sln) not found
  → add setupSolutionPath in appsettings (PART A)

ERROR: devenv.exe not found
  → install VS; ensure ResolveVisualStudioIdePath finds Community/Professional/Enterprise

ERROR: Setup build failed with exit code N
  → install "Installer Projects" extension; open .sln in VS once; rebuild
    Web2ClientBridge.Setup manually to confirm vdproj builds

ERROR: Setup MSI not found under ...\Web2ClientBridge.Setup
  → devenv did not produce MSI (see previous); or output went elsewhere —
    PART D recursive *.msi search should find it if it exists

WARN: Publish output not found for Web2ClientBridge
  → PART C AspNetMvc bin\Release\Publish lookup missing, OR FolderProfile /
    publish failed (fix web build first — see web-to-client-bridge-build-publish.txt)

MSB4078: .vdproj is not supported by MSBuild
  → ignore if you still build .sln; prefer projectPath = .csproj (PART A)
