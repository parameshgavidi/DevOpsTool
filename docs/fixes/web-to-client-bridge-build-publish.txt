FIX: Build failed — FolderProfile.pubxml missing
--------------------------------------------------------------------------------
OUTPUT LOG errors:

  The value for PublishProfile is set to 'FolderProfile', expected to find the
  file at:
    ...\WebToClientBridge\WebToClientBridge\Properties\PublishProfiles\FolderProfile.pubxml
  but it could not be found.

  PublishProfile(FolderProfile) is set. But the $(WebPublishMethod) does not
  have a valid value. Current Value is "".

  ValidatePublishProfileSettings target failed

Also (warning only — ignore for web publish):
  MSB4078: The project file "Web2ClientBridge.Setup.vdproj" is not supported
  by MSBuild and cannot be built.

Cause:
  buildCommand used /p:PublishProfile=FolderProfile but that .pubxml does not
  exist on disk. Web publish validation then fails (WebPublishMethod empty).


--------------------------------------------------------------------------------
RECOMMENDED FIX (do both A + B)
--------------------------------------------------------------------------------

A) Create FolderProfile.pubxml
   Path (must match exactly):
     WebToClientBridge\WebToClientBridge\Properties\PublishProfiles\FolderProfile.pubxml

   File contents:

<?xml version="1.0" encoding="utf-8"?>
<Project ToolsVersion="4.0" xmlns="http://schemas.microsoft.com/developer/msbuild/2003">
  <PropertyGroup>
    <WebPublishMethod>FileSystem</WebPublishMethod>
    <PublishProvider>FileSystem</PublishProvider>
    <LastUsedBuildConfiguration>Release</LastUsedBuildConfiguration>
    <LastUsedPlatform>Any CPU</LastUsedPlatform>
    <LaunchSiteAfterPublish>False</LaunchSiteAfterPublish>
    <ExcludeApp_Data>False</ExcludeApp_Data>
    <publishUrl>bin\Release\Publish</publishUrl>
    <DeleteExistingFiles>True</DeleteExistingFiles>
  </PropertyGroup>
</Project>

   Create folders Properties\PublishProfiles if missing, then save the file.
   Rebuild from the DevOps tool after this exists.


--------------------------------------------------------------------------------
TEAM NOTE — commit FolderProfile.pubxml to git (preferred)
--------------------------------------------------------------------------------
FolderProfile.pubxml is NOT currently committed in the GSS repo.

Ask the team to commit this file to the branch used by the DevOps tool:

  WebToClientBridge\WebToClientBridge\Properties\PublishProfiles\FolderProfile.pubxml

Why commit (best way):
  - Required for DeployOnBuild + PublishProfile=FolderProfile on every build machine
  - Survives Get latest / clean checkouts — no one-off local file
  - Same publish settings for all agents / teammates

Local-only (temporary OK):
  - You may create the file on your build PC now to unblock yourself
  - stash-based gitLatestCommand can keep local edits for a while
  - Fragile: lost if folder is cleaned, another machine builds, or someone
    else runs the tool without the file

Recommended message to team:
  "Please commit Properties\PublishProfiles\FolderProfile.pubxml for
   WebToClientBridge so msbuild DeployOnBuild / PublishProfile=FolderProfile
   works on all build machines. File is missing from git today and causes
   ValidatePublishProfileSettings to fail."

Practical path: create locally to unblock → team commits same file → permanent.
