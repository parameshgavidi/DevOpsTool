FIX — restore ReportViewer 12 on the build machine (keep local OK)
--------------------------------------------------------------------------------
1) Open Visual Studio → Tools → NuGet Package Manager → Package Manager Console

2) Set Default project: SSRSReportingObjects
   (under Shared Components)

3) Install ReportViewer 12 runtime packages:

     Install-Package Microsoft.ReportViewer.Runtime.WebForms -Version 12.0.2402.15
     Install-Package Microsoft.ReportViewer.Runtime.Common -Version 12.0.2402.15

   If those package IDs are unavailable on your feed, try:

     Install-Package Microsoft.ReportViewer.WebForms.v12

4) If MSB3245 for System.Runtime.Serialization.Primitives remains:

     Install-Package System.Runtime.Serialization.Primitives -Version 4.1.2

5) Rebuild Shared Components / the solution that references SSRSReportingObjects.

6) Confirm Error List: CS0234 and ReportViewer MSB3245 are GONE.
   Unused-variable warnings (CS0219/CS0168) can stay.

--------------------------------------------------------------------------------
DevOps tool — buildCommand / gitLatest (if Shared Components is an app)
--------------------------------------------------------------------------------
appsettings does NOT list NuGet package names. Put only:

  "buildCommand"  → whatever msbuild/dotnet command builds this sln/csproj
  "gitLatestCommand" → stash/fetch/restore/pop for the folder

If Install-Package is LOCAL only (not pushed to remote), use empty-stash-safe
gitLatestCommand so Get latest does not wipe packages:

  git stash push -m "devops-pre-build" -- "Shared Components" && git fetch && git restore --source=@{u} --staged --worktree -- "Shared Components" && (git stash pop || ver > nul)

Do NOT put "Microsoft.ReportViewer.WebForms" into a build field in appsettings.
The build field (buildCommand) runs msbuild/dotnet — packages must already be
restored or present under packages\ / references.


Example if you add Shared Components as a buildable app:

{
  "name": "Shared Components",
  "type": "DotNetFramework",
  "projectPath": "Shared Components\\<YourSharedComponents.sln>",
  "gitLatestCommand": "git stash push -m \"devops-pre-build\" -- \"Shared Components\" && git fetch && git restore --source=@{u} --staged --worktree -- \"Shared Components\" && (git stash pop || ver > nul)",
  "buildCommand": "msbuild \"{projectFile}\" /p:Configuration=Release /m",
  "outputSubfolder": "SharedComponents"
}

Replace <YourSharedComponents.sln> with the real .sln name under Shared Components.
