--------------------------------------------------------------------------------
WHAT IS WRONG (from the 16 Oct 2026 screenshots)
--------------------------------------------------------------------------------
The installer copied files, then died at the LAST step:

  Product: Microsoft.VisualStudio.Product.Professional
  Action:  Finalize
  Tool:    vsfinalizer.exe
  Code:    1  (Incorrect function)
  Path:    C:\Program Files\Microsoft Visual Studio\18\Professional
  Log:     C:\Users\XHS2H0\AppData\Local\Temp\dd_setup_20261016133437_353_Microsoft.VisualStudio.Product.Professional.log

This is NOT a VS 2019 problem.
This is NOT a Crystal Reports problem.
Installing on F: is NOT a problem. You MUST install on F:.

The last run installed to C:, not F:. Location in the installer was:

  C:\Program Files\Microsoft Visual Studio\18\Professional

C: is 119 GB total.
  Before install: 28.0 GB free
  Product size:   18.55 GB
  After failure:  22.1 GB free

C: ran out of working space during "Optimizing assemblies..." (99%).
vsfinalizer.exe then returned "Incorrect function".

F: has 91.4 GB free. Use F: for the IDE and the download cache.

VS 2019 (16.11.60) stays. Do not uninstall it.
Crystal Reports stays. Do not uninstall it.
Sentinel Agent can block vsfinalizer.exe. Pause it for this install.

Do NOT click Repair, Modify, or Launch on the 2026 card that says
"Setup completed with warnings". That instance is on C: and is broken.
Remove it, then do a NEW install on F:.

--------------------------------------------------------------------------------
HOW TO OPEN ADMINISTRATOR COMMAND PROMPT
--------------------------------------------------------------------------------
1. Close the Visual Studio Installer. Close the error popup.
2. Close every Visual Studio window.
3. Start → type: cmd
4. Right-click Command Prompt → Run as administrator
5. Click Yes


================================================================================
STEP 1 — pause SentinelOne (2 minutes)
================================================================================
1. Start → type: Sentinel
2. Open Sentinel Agent / SentinelOne.
3. Pause protection / disable for 4 hours if the screen allows it.
4. If you cannot pause it (company policy), continue anyway.
   If STEP 7 fails at vsfinalizer again, you MUST get Sentinel paused
   and repeat from STEP 3.


================================================================================
STEP 2 — remove ONLY Visual Studio 2026
================================================================================
Paste this block. Press Enter. Wait until the prompt comes back.
It can take several minutes. Do not close the window.

  taskkill /IM setup.exe /F >nul 2>&1
  taskkill /IM vs_installer.exe /F >nul 2>&1
  taskkill /IM vs_installershell.exe /F >nul 2>&1
  taskkill /IM devenv.exe /F >nul 2>&1
  "C:\Program Files (x86)\Microsoft Visual Studio\Installer\InstallCleanup.exe" -i 18

If it says the file is missing:

  1. Run  %USERPROFILE%\Downloads\vs_Professional.exe  as Administrator.
  2. Wait until the workload screen appears.
  3. Close that window. Do not click Install.
  4. Run the InstallCleanup line again.


================================================================================
STEP 3 — delete leftover 2026 files on C:
================================================================================
Paste this whole block. Press Enter.

  rmdir /s /q "C:\Program Files\Microsoft Visual Studio\18"
  rmdir /s /q "C:\Program Files (x86)\Microsoft Visual Studio\Installer.old"
  rmdir /s /q "C:\ProgramData\Microsoft\VisualStudio\Packages\_Instances\c0551210"

If rmdir says "The system cannot find the file specified", that is OK.

If a file is in use, reboot, open Administrator cmd again, and
re-run only this STEP 3 block.


================================================================================
STEP 4 — free C: and confirm F:
================================================================================
Paste this whole block. Press Enter.

  cleanmgr /d C
  mkdir "F:\Program Files\Microsoft Visual Studio\18"
  mkdir "F:\VS2026\Packages"
  mkdir "F:\VS2026\Temp"
  echo ----- FREE SPACE -----
  wmic logicaldisk get caption,freespace,size

Disk Cleanup window will open:
  Tick Recycle Bin, Temporary files, Delivery Optimization, Thumbnails.
  Click Clean up system files if you see it.
  Click OK. Wait until it finishes.

READ the numbers. Free space is BYTES.

  C: must be at least  30000000000   (30 GB)
  F: must be at least  40000000000   (40 GB)

If C: is still under 30 GB:
  1. Empty Recycle Bin
  2. Delete old files in  %USERPROFILE%\Downloads  EXCEPT the new
     vs_professional.exe you will download in STEP 6
  3. Run cleanmgr /d C again
  4. Re-run the wmic line
  5. Do NOT go to STEP 7 until C: is over 30 GB

F: at ~91 GB is already enough. Do not format F:. Do not move VS 2019.


================================================================================
STEP 5 — point the VS download cache at F:
================================================================================
Paste this whole block. Press Enter.

  mkdir "F:\VS2026\Packages"
  icacls "F:\VS2026\Packages" /grant SYSTEM:(OI)(CI)F /grant Administrators:(OI)(CI)F
  reg add "HKLM\SOFTWARE\Policies\Microsoft\VisualStudio\Setup" /v CachePath /t REG_SZ /d "F:\VS2026\Packages" /f
  reg query "HKLM\SOFTWARE\Policies\Microsoft\VisualStudio\Setup" /v CachePath

The last line MUST print:

  CachePath    REG_SZ    F:\VS2026\Packages

If it does not, run the reg add line again.


================================================================================
STEP 6 — reboot, then download a NEW installer
================================================================================
1. Reboot the machine now.
2. After reboot, pause SentinelOne again (same as STEP 1).
3. Open Administrator Command Prompt again.
4. Delete the old bootstrapper (it is only 5 MB and can be stale):

     del /q "%USERPROFILE%\Downloads\vs_Professional.exe"
     del /q "%USERPROFILE%\Downloads\vs_professional.exe"

5. Download a NEW file in Edge/Chrome:

     https://aka.ms/vs/18/stable/vs_professional.exe

   Official page if that link redirects oddly:
     https://visualstudio.microsoft.com/downloads/
     → Visual Studio Professional 2026 → Download

6. Save it to Downloads. Do not run it yet.
   If the file is named  vs_professional (1).exe  rename it to
   vs_professional.exe.


================================================================================
STEP 7 — install Visual Studio 2026 ON F: (the actual fix)
================================================================================
Paste this whole block in Administrator Command Prompt. Press Enter.
Do not use the GUI. The GUI defaulted you to C: last time.

  set TEMP=F:\VS2026\Temp
  set TMP=F:\VS2026\Temp
  mkdir F:\VS2026\Temp
  cd /d %USERPROFILE%\Downloads

  vs_professional.exe --wait --passive --norestart --nocache ^
    --installPath "F:\Program Files\Microsoft Visual Studio\18\Professional" ^
    --path cache="F:\VS2026\Packages" ^
    --add Microsoft.VisualStudio.Workload.NetWeb;includeRecommended ^
    --add Microsoft.VisualStudio.Workload.NetCrossPlat;includeRecommended ^
    --add Microsoft.VisualStudio.Workload.ManagedDesktop;includeRecommended

A progress window will open. Leave it alone until the cmd prompt
returns. This can take 30–90 minutes.

Do NOT click Cancel.
Do NOT pick C:\Program Files\...
Do NOT migrate from the old 18.11 instance.

When the prompt returns, paste:

  echo EXIT=%ERRORLEVEL%

Need:
  EXIT=0     success
  EXIT=3010  success, reboot required → reboot, then go to STEP 8

Any other number = failed.

If the window closes in under 1 minute and the text mentions cache
or path, paste STEP 7 again but DELETE this one line:

  --path cache="F:\VS2026\Packages" ^

Keep --installPath on F: and keep --nocache. Then go to STEP 8.

If it still fails, go to STEP 10. Do not click Repair.


================================================================================
STEP 8 — prove it is installed on F:
================================================================================
Paste this whole block. Press Enter.

  echo ----- C: and F: space -----
  wmic logicaldisk get caption,freespace
  echo ----- IDE -----
  dir "F:\Program Files\Microsoft Visual Studio\18\Professional\Common7\IDE\devenv.com"
  echo ----- MSBuild -----
  dir "F:\Program Files\Microsoft Visual Studio\18\Professional\MSBuild\Current\Bin\amd64\MSBuild.exe"
  echo ----- MUST BE EMPTY / NOT EXIST -----
  dir "C:\Program Files\Microsoft Visual Studio\18\Professional\Common7\IDE\devenv.com"
  echo ----- SDKs -----
  dotnet --list-sdks

MUST be true:
  [ ] devenv.com exists under F:\...18\Professional\...
  [ ] MSBuild.exe exists under F:\...18\Professional\...
  [ ] C:\Program Files\Microsoft Visual Studio\18\Professional\...\devenv.com
      is NOT found  (2026 is not on C:)
  [ ] dotnet --list-sdks shows a 10.0.x line

Then:

  "F:\Program Files\Microsoft Visual Studio\18\Professional\Common7\IDE\devenv.exe"

Help → About Visual Studio must say:
  Visual Studio Professional 2026
with NO yellow "Setup completed with warnings".


================================================================================
STEP 9 — after a good install (once)
================================================================================
1. Turn SentinelOne protection back ON.
2. In VS 2026: sign in with the Visual Studio subscription.
3. Extensions → Manage Extensions → search:
     Microsoft Visual Studio Installer Projects
   Install it on THIS 2026 instance. Needed for .vdproj / MSI.
4. Close VS.
5. Start menu → Developer Command Prompt for VS 2026:

     dotnet workload list

   If maui-windows is missing:

     dotnet workload install maui-windows

This repo's tools should use:

  F:\Program Files\Microsoft Visual Studio\18\Professional\Common7\IDE\devenv.com
  F:\Program Files\Microsoft Visual Studio\18\Professional\MSBuild\Current\Bin\amd64\MSBuild.exe


================================================================================
STEP 10 — only if STEP 7 failed
================================================================================
Paste this. Copy ALL of the output and send it.

  powershell -NoProfile -Command "Get-ChildItem $env:TEMP\dd_setup*.log,$env:TEMP\dd_installer*.log,F:\VS2026\Temp\dd_setup*.log,F:\VS2026\Temp\dd_installer*.log -ErrorAction SilentlyContinue | Sort-Object LastWriteTime -Descending | Select-Object -First 4 | ForEach-Object { Write-Host '====' $_.FullName; Select-String -Path $_.FullName -Pattern 'Error|Failed|Exception|vsfinalizer|Incorrect function' | Select-Object -Last 50 }"

  echo ----- space -----

  echo ----- 18 folders -----
  dir "C:\Program Files\Microsoft Visual Studio"

Also screenshot:
  Visual Studio Installer → Installed tab
  SentinelOne pause status if you can open it

Do not send the OK popup. It has no useful detail.


--------------------------------------------------------------------------------
ANSWERS TO THE QUESTIONS
--------------------------------------------------------------------------------
1. Why 2026 is not installing
   vsfinalizer.exe failed while finalizing a C: install that did not
   have enough free space.

2. Why the previous steps did not work
   Resetting the Installer folder (Installer.old) only rebuilds the
   installer app. The broken 18 product stayed. The new attempt then
   installed to C: again (Location was still
   C:\Program Files\Microsoft Visual Studio\18\Professional).

3. System details from the screenshots are enough to pick the fix.
   Send STEP 10 output only if STEP 7 fails.

4. Follow STEP 1 → STEP 9 in order. Do not skip STEP 7 command line.

5. Problem location
   C:\Program Files\Microsoft Visual Studio\18\Professional
   plus C: at 22–28 GB free, plus Sentinel Agent.
   Not VS 2019. Not Crystal Reports. Not F:.

6. VS 2019 installed — keep it. Side-by-side is supported.
   Version on this machine: 16.11.60.

7. Crystal Reports — keep it. Do not uninstall those products.

8. Want to install on F: — YES. That is required on this machine.
   F: is not the problem. C: as the install target is the problem.

9. Drive capacity
   C: 119 GB, 22.1 GB free after the failed run. Too small for 18.55 GB
   on C: plus cache/temp/ngen.
   F: 119 GB, 91.4 GB free. Use this for the IDE.

10. Extra info needed now
    None. Do the steps. Send STEP 10 output only if it fails again.
