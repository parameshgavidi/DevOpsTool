SEPARATE Get latest from Build
No GetLatestFromRepoAsync when clicking Build / Build All
================================================================================

REQUIREMENT
-----------
Get latest and Build are SEPARATE actions now:

  1. Click Get latest  → pull code + show APPLICATIONS grid
  2. Click Build       → build only (NO git latest)

Do NOT call GetLatestFromRepoAsync inside BuildApplication anymore.


--------------------------------------------------------------------------------
1) BuildTab.razor — REMOVE this block from BuildApplication
--------------------------------------------------------------------------------
Find and DELETE (or comment out) this entire block near the start of
BuildApplication, BEFORE RestorePackagesAsync / CleanPrecompiled / msbuild:

        // ---- REMOVE: no git latest on Build ----
        if (!await GetLatestFromRepoAsync(app, workingDir, cancellation))
        {
            app.Status = "Failed";
            await InvokeAsync(StateHasChanged);
            return;
        }

Also remove any similar one-liner:

        await GetLatestFromRepoAsync(app, workingDir, cancellation);


--------------------------------------------------------------------------------
2) BuildApplication — updated order (AFTER remove)
--------------------------------------------------------------------------------
After resolving workingDir / projectFile, go straight to restore / clean / build:

    private async Task BuildApplication(Application app, CancellationToken cancellation)
    {
        // ... existing setup: Status = Building, workingDir, projectFile, etc. ...

        // NO GetLatestFromRepoAsync here — user already clicked Get latest separately

        if (!await RestorePackagesAsync(app, projectFile, isLegacy, workingDir, cancellation))
        {
            app.Status = "Failed";
            await InvokeAsync(StateHasChanged);
            return;
        }

        if (!await CleanPrecompiledOutputAsync(app, workingDir))
        {
            app.Status = "Failed";
            await InvokeAsync(StateHasChanged);
            return;
        }

        // existing: RunCommandAsync(buildCommand) → archive/copy on exit == 0
        // existing: app.Status = exit == 0 ? "Success" : "Failed";
    }

Adjust method names to match yours (RestorePackagesAsync / CleanPrecompiledOutputAsync
may already be present). The only required change is: no git latest call.


--------------------------------------------------------------------------------
3) Get latest — toolbar button ONLY (uses appsettings + GetLatestFromRepoAsync)
--------------------------------------------------------------------------------
REPLACE any hardcoded pull in GetLatestAndShowAppsAsync.

Correct flow (full code in docs/fixes/buildtab-get-latest-show-apps.txt):

    await LoadApplicationsFromConfigAsync();          // load ALL apps from appsettings
    foreach (var app in BuildApps)
    {
        await GetLatestFromRepoAsync(app, root, ...); // uses app.GitLatestCommand
    }
    _showApplications = true;

KEEP the GetLatestFromRepoAsync method — it is called from Get latest, not from Build.


--------------------------------------------------------------------------------
4) appsettings.json — gitLatestCommand (USED by Get latest)
--------------------------------------------------------------------------------
Per-app "gitLatestCommand" IS used when you click Get latest.
It is NOT used when you click Build.

Each app needs its own command, e.g.:

  "gitLatestCommand": "git stash push -m \"devops-pre-build\" -- \"Web Services\\GSSWebService\" && git fetch && git restore --source=@{u} --staged --worktree -- \"Web Services\\GSSWebService\" && git stash pop"

Do NOT remove gitLatestCommand from appsettings.


--------------------------------------------------------------------------------
5) Flow (new)
--------------------------------------------------------------------------------
  OnInitialized
      → LoadAppSettings() → paths + BuildApps (grid hidden)

  Click Get latest
      → Load all apps from appsettings into BuildApps
      → For each app: GetLatestFromRepoAsync (app.GitLatestCommand)
      → show APPLICATIONS grid

  Click Build / Build All
      → RestorePackagesAsync (if any)
      → CleanPrecompiledOutputAsync (if any)
      → msbuild / publish / copy
      → NO git
