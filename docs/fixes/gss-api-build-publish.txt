--------------------------------------------------------------------------------
FIX: Get latest failed exit code 1 (No stash entries found)
--------------------------------------------------------------------------------
Symptom in OUTPUT LOG:
  No local changes to save
  No stash entries found.
  [ERROR] Git latest failed for GSS API with exit code 1
  Get latest complete — OK: 0, Failed: 1

Cause:
  No local edits under Web Services\GSSApi → stash push creates NO stash
  (message: "No local changes to save", exit 0).
  Later "git stash pop" then fails with "No stash entries found" (exit 1).
  Because the command uses &&, the whole gitLatestCommand fails.

Fix:
  End with: (git stash pop || ver > nul)
  so empty stash is OK on Windows cmd. Real fetch/restore failures still fail
  (they run before stash pop).

OLD (fails when clean working tree):
  ... && git stash pop

NEW:
  ... && (git stash pop || ver > nul)

- @{u} must be set on the current branch (upstream tracking).
