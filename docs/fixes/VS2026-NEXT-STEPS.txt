--------------------------------------------------------------------------------
STEP A — close Visual Studio
--------------------------------------------------------------------------------
Click OK on the red error popup.
Close Visual Studio if it is still open.
Close Visual Studio Installer.


--------------------------------------------------------------------------------
STEP B — remove ONLY the broken VS 2026 instance
--------------------------------------------------------------------------------
Open Administrator Command Prompt (Start → cmd → Run as administrator).

Paste this whole block. Press Enter. Wait until the prompt comes back.

  taskkill /IM devenv.exe /F >nul 2>&1
  taskkill /IM vs_installer.exe /F >nul 2>&1
  taskkill /IM vs_installershell.exe /F >nul 2>&1
  "C:\Program Files (x86)\Microsoft Visual Studio\Installer\InstallCleanup.exe" -i 18
  rmdir /s /q "F:\Program Files\Microsoft Visual Studio\18"

"File not found" is OK.
Never run InstallCleanup.exe without  -i 18


--------------------------------------------------------------------------------
STEP C — create the install script
--------------------------------------------------------------------------------
Paste this whole block. Press Enter.

  mkdir F:\VS2026
  mkdir F:\VS2026\Temp
  mkdir F:\VS2026\Packages

  (
  echo @echo off
  echo set TEMP=F:\VS2026\Temp
  echo set TMP=F:\VS2026\Temp
  echo cd /d %%USERPROFILE%%\Downloads
  echo start /wait vs_Professional.exe --passive --norestart --installPath "F:\Program Files\Microsoft Visual Studio\18\Professional" --path cache="F:\VS2026\Packages" --add Microsoft.VisualStudio.Workload.CoreEditor;includeRecommended
  echo echo EXIT=%%ERRORLEVEL%%
  echo pause
  ) > F:\VS2026\install-core.bat

This installs ONLY the core IDE first (no ASP.NET, no MAUI).
That is required so devenv.exe and its components can finish.


--------------------------------------------------------------------------------
STEP D — run the script
--------------------------------------------------------------------------------
Paste this. Press Enter.

  F:\VS2026\install-core.bat

A progress window must stay open for a long time (often 20–60 minutes).
Do not close Command Prompt.
Do not click Cancel.

When it says  Press any key to continue  look at EXIT=

  EXIT=0      good
  EXIT=3010   good, reboot, then continue STEP E
  any other   failed — go to STEP G
