================================================================================
DeploymentTool.razor — HasSuccessfulBuild compile error on save
================================================================================

SYMPTOM
-------
After uncommenting:

    HasSuccessfulBuild = HasSuccessfulBuild || hasSuccessfulBuild;

Save / build fails (red squiggle on HasSuccessfulBuild).

SelectTab also uses it:

    if (!HasSuccessfulBuild && tabName != "BUILD") return;


FIX — declare the field once in DeploymentTool.razor @code
-----------------------------------------------------------
Add this with your other private fields (near ActiveTab, etc.):

    private bool HasSuccessfulBuild;

Then HandleBuildSuccessChanged must be:

    private Task HandleBuildSuccessChanged(bool hasSuccessfulBuild)
    {
        HasSuccessfulBuild = HasSuccessfulBuild || hasSuccessfulBuild;
        return InvokeAsync(StateHasChanged);
    }

And SelectTab stays:

    private void SelectTab(string tabName)
    {
        if (!HasSuccessfulBuild && tabName != "BUILD") return;
        ActiveTab = tabName;
    }


NOTES
-----
- Field name: HasSuccessfulBuild (PascalCase) — matches SelectTab.
- Parameter name: hasSuccessfulBuild (camelCase) — different; that is fine.
- Do NOT comment out the assignment again; without it tabs stay locked on BUILD.
- DeployTab needs no HasSuccessfulBuild — only DeploymentTool.


CHECKLIST
---------

[ ] assignment uncommented in HandleBuildSuccessChanged
[ ] return InvokeAsync(StateHasChanged);
[ ] save / build — no red squiggles
